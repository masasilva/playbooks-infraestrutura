# ✅ Checklist Pós-Instalação - Windows Server

- Atualizar sistema operacional via Windows Update
- Alterar nome do host
- Configurar IP fixo
- Instalar funções e recursos (Ex: AD DS, DNS, DHCP)
- Instalar antivírus corporativo
- Configurar monitoramento (Zabbix, SolarWinds)
- Aplicar políticas de segurança
- Ingressar no domínio
- Habilitar RDP com segurança (NLA, firewall, portas)
