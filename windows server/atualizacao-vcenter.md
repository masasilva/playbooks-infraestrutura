# 🚀 Atualização do vCenter Server

## Passos

1. Realizar backup completo do vCenter (VCSA)
2. Validar versão de origem e destino compatíveis
3. Baixar o ISO do upgrade
4. Montar ISO e iniciar upgrade pelo Stage 1
5. Após validações, prosseguir para Stage 2
6. Validar serviços, permissões e alertas pós-upgrade
