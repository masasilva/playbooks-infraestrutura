# 🔐 Hardening Básico - Windows Server

## Objetivo
Reduzir a superfície de ataque e aplicar medidas mínimas de segurança em servidores Windows.

---

## Itens Recomendados

- Desabilitar SMBv1
- Configurar senha de BIOS/UEFI
- Renomear conta de administrador
- Desabilitar contas Guest
- Aplicar GPOs de segurança
- Ativar o firewall do Windows
- Aplicar política de senha forte
- Habilitar registro de eventos (auditoria)
- Configurar proteção contra RDP Brute Force
