# 🔐 Segurança - Checklist MFA, VPN e Firewall

- MFA habilitado em sistemas críticos (AD, VPN, O365)
- VPN com autenticação multifator
- Políticas de senha configuradas via GPO
- Auditoria de logon habilitada
- Firewall com regras mínimas e log de conexões
- Permissões de pastas com "Least Privilege"
- Aplicações com Hardening + Certificados válidos
