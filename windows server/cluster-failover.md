# 🔄 Microsoft Cluster Failover - Guia Rápido

## Pré-requisitos

- Windows Server Datacenter
- 2 ou mais nós com mesmo SO e patch level
- Armazenamento compartilhado (SAN ou CSV)

## Etapas

1. Instalar recurso de "Failover Clustering"
2. Validar configuração com o assistente
3. Criar cluster com IP virtual
4. Configurar Roles: File Server, SQL, etc.
5. Testar failover e monitorar eventos
