# 📚 Playbooks de Infraestrutura

Este repositório reúne **playbooks técnicos para profissionais de infraestrutura**, com foco em ambientes Microsoft, virtualização (VMware), segurança, backup, redes e automação.

📌 Ideal para consultas rápidas, padronização de processos e base de conhecimento para times técnicos sêniores.

---

## 🔖 Categorias

- **Windows Server**: hardening, checklist pós-instalação, clustering.
- **VMware**: lifecycle manager, atualizações, boas práticas.
- **Backup**: rotinas com Veeam.
- **Segurança**: MFA, VPN, firewall, permissões.
- **Documentação**: índice e estruturação para times.
